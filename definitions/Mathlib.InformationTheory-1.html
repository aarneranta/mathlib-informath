Mathlib.InformationTheory.Coding.PrefixFree

InformationTheory.IsPrefixFreedefMathlib.InformationTheory.Coding.PrefixFree, predicate
Wording
S is a prefix free (from the name)
English
Let $S$ be an element of the power set of the set of lists of elements of $x$. Then $S$ is a prefix free, if for all lists $x_{1}$ of elements of $x$, if $x_{1}$ is an element of $S$, then for all lists $y$ of elements of $x$, if $y$ is an element of $S$, then if $\operatorname{IsPrefix}$ holds for $x_{1}$ and $y$, then $\EqtMACRoH {x_{1}}{y}$.

InformationTheory.klFundefMathlib.InformationTheory.KullbackLeibler.KLFun, function or constant
Wording
the function of x (from the docstring)
English
Let $x$ be a real number. Then the function of $x$ is a real number defined as the difference between the sum of the product of $x$ and the logarithm of $x$ and $1$ and $x$.
