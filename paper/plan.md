# Plan for a paper on Mathlib-Informath

## Goal

Write a 12-page paper in EasyChair style entitled "Informalizing Lean" and aimed for an audience familiar with Lean but not knowing GF or Informath.

The contents should be as follows:

- and the documentation problem of formal code, in particular when autoformalization produces it
- Lean and its massive Mathlib as tool, resource, and test case
- GF, Dedukti and Informath
- prior work: Mizar, Coscoy et al, Massot's verbose lean etc

- the steps of converting lean code to natural language
- inferring the symbol tables
- how much of this comes from Informath, docstrings, other resources, prompts, Claude
- examples of all kinds of definitions, theorems, proof - mostly nice ones but also some bad ones

- results: what has been done and how much
- known problems and open issues

You can use the gf-bib.bib references and also text from arxiv-informath.tex as well as images from resources/.

Make it clear that Claude is a coauthor.

Include proper reference list.
